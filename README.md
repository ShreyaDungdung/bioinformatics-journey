## Current Progress
# Weekly Reflections

### Day 1
Started building the foundation by understanding what bioinformatics is and how computational tools support biological research. Explored biological databases (NCBI and UniProt) and learned the basics of Python, including variables and data types. This day highlighted the importance of combining biological knowledge with programming skills.

### Day 2
Focused on Python fundamentals such as loops, functions, and file handling while getting introduced to Biopython. Reading FASTA files was my first experience working with biological sequence data programmatically, making the connection between coding and biology much clearer.

### Day 3
Learned how biological sequences can be manipulated using Python. Practicing sequence operations reinforced the idea that many bioinformatics analyses rely on simple computational concepts applied to biological data. Writing small scripts improved both my confidence and problem-solving approach.

### Day 4
Worked on improving code organization and handling biological data more efficiently. I realized that writing clean, readable code is just as important as producing the correct output, especially for reproducible scientific analyses.

### Day 5
Applied Python to solve practical bioinformatics tasks and gained a better understanding of how automation simplifies repetitive analyses. This was the point where programming started to feel like a useful research tool rather than just another subject to learn.

### Day 6
Revisited previous concepts through practice and debugging. Debugging helped me understand my mistakes instead of simply correcting them, reinforcing the value of patience and consistency when learning technical skills.

### Day 7
Completed the first week with a much stronger understanding of both Python fundamentals and introductory bioinformatics concepts. More importantly, I established a consistent learning routine and created a solid foundation that I can build on in the coming weeks.
