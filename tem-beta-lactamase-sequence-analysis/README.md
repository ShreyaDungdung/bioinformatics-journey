#  TEM Beta-Lactamase Sequence Analysis

## Project Overview
This project explores sequence similarities and variations among five selected TEM-type beta-lactamase nucleotide sequences using bioinformatics tools and Python-based analysis.

## Objectives
- Retrieve selected nucleotide sequences from NCBI
- Perform multiple sequence alignment
- Calculate pairwise nucleotide sequence identity
- Explore relationships among sequences using phylogenetic analysis
- Investigate nucleotide and preliminary amino acid variations

## Tools & Technologies
- **NCBI Nucleotide:** Sequence retrieval
- **Clustal Omega:** Multiple sequence alignment
- **Python:** Computational analysis
- **Biopython:** Biological sequence processing
- **Pandas:** Tabular data analysis
- **Phylogenetic analysis tool:** Tree construction and visualization

## Workflow
1. Retrieve nucleotide sequences from NCBI
2. Align the selected sequences using Clustal Omega
3. Process alignment files using Python and Biopython
4. Calculate pairwise sequence identity
5. Identify variable nucleotide positions
6. Translate coding sequences and explore amino acid variation
7. Construct and interpret a phylogenetic tree
8. Document the workflow, results, and limitations

## Important Note
This is an exploratory computational analysis of selected sequences. Sequence similarity and predicted amino acid differences alone do not establish differences in antibiotic resistance or biological function.
